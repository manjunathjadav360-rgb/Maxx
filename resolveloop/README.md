# ResolveLoop

ResolveLoop is a small interactive prototype exploring a clearer way for buyers and merchants to review purchase problems together.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Try it
- Choose a proposed next step: replacement, partial refund, full refund, or request evidence.
- Review and edit the decision note.
- Record the sample decision, then reset to try another path.

## Important limits
This version uses illustrative case data and browser-only interactions. It does not connect to PayPal, verify a real order, issue a refund, or create a shipment. A production version would need a secure server, authenticated users, trusted order and policy data, server-side audit records, and PayPal Sandbox integration before any live payment functionality.

## Project status
Early prototype built to test the shared-case workflow and human approval boundary. Feedback and contributions are welcome.
